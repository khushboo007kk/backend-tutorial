# Node.js Express MongoDB CRUD API

This project is a REST API built using Node.js, Express.js,
MongoDB Atlas and Mongoose.

## Features

- Create User
- Get All Users
- Get User by ID
- Update User
- Delete User

## Technologies

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Postman

## Installation

1. Clone the repository.
2. Run npm install.
3. Create a .env file with PORT and MONGO_URI.
4. Run npm run dev.

## API Endpoints

POST /api/users
GET /api/users
GET /api/users/:id
PUT /api/users/:id
DELETE /api/users/:id
